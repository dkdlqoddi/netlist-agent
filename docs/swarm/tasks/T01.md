# T01 도메인 데이터 모델 및 기본 테스트 환경 구축

- 역할: 모델 정의
- 웨이브: 1
- 선행: 없음
- 대상 spec: docs/core/specs/netlist-parser.md
- 협업 스쿼드: swarm-worker (구현) ↔ swarm-verifier (검증) ↔ swarm-reviewer (리뷰)
- 소유 파일: `pyproject.toml` (신규), `src/models.py` (신규), `tests/test_models.py` (신규)
- 참고 파일: `docs/core/rules.md`, `docs/core/specs/netlist-parser.md`

## 목표

넷리스트 구성요소(Module, Port, Wire, Instance, PinConnection, Alias, Netlist)를 표현하는 Python 3.10 dataclass 도메인 모델을 정의합니다.
프로젝트의 pytest 실행 및 `src/` 모듈 검색을 보장하는 `pyproject.toml` 설정을 구성하고 모델 생성/검증 단위 테스트를 작성합니다.
스펙의 요구사항 1번, 3번과 규칙의 dataclass 및 순수 데이터 모델 정의 관례를 충족합니다.

## 해야 할 일

1. `pyproject.toml` 파일을 생성하고 pytest 도구 설정(`[tool.pytest.ini_options]` 하위에 `pythonpath = ["src"]`, `testpaths = ["tests"]`)을 작성합니다.
2. `src/models.py` 파일을 생성하고 `@dataclass(slots=True)`를 적용하여 다음 데이터 클래스를 구현합니다:
   - `Port`: `name: str`, `direction: str` ('input' 또는 'output'), `width: int = 1`, `msb: int = 0`, `lsb: int = 0`
   - `Wire`: `name: str`, `data_type: str = "wire"` ('wire' 또는 'logic'), `width: int = 1`, `msb: int = 0`, `lsb: int = 0`, `is_implicit: bool = False`
   - `PinConnection`: `pin_name: str`, `net_name: str` (빈 핀인 경우 `net_name=""`)
   - `Instance`: `instance_name: str`, `cell_type: str`, `connections: list[PinConnection] = field(default_factory=list)`
   - `Alias`: `net_a: str`, `net_b: str`
   - `Module`: `name: str`, `ports: list[Port] = field(default_factory=list)`, `wires: list[Wire] = field(default_factory=list)`, `instances: list[Instance] = field(default_factory=list)`, `aliases: list[Alias] = field(default_factory=list)`
   - `Netlist`: `modules: list[Module] = field(default_factory=list)`
   - `NetlistError`: 도메인 최상위 예외 클래스
3. `tests/test_models.py`에 각 데이터 모델 객체 인스턴스화, `is_implicit` 기본값 검증, 필드 접근 및 직렬화 보조 테스트를 작성합니다.

## 협업 프로토콜

1. 구현(`swarm-worker`) 완료 후 `send_message`로 `swarm-verifier`에게 `[PHASE: VERIFY_REQUEST]`를 전송합니다.
2. `swarm-verifier`는 검증 명령(`pytest tests/test_models.py`)을 실행하고 실패 시 에러 요약 로그를 담아 `[PHASE: VERIFY_RESULT] FAIL`을 회신하며, 성공 시 `[PHASE: VERIFY_RESULT] PASS`를 회신합니다. 실패 시 `swarm-worker`가 코드를 수정하고 재검증을 요청합니다.
3. 검증 통과 시 `swarm-worker`는 `send_message`로 `swarm-reviewer`에게 `[PHASE: REVIEW_REQUEST]`를 전송합니다.
4. `swarm-reviewer`는 git diff를 검토하여 `docs/core/rules.md` 불변 규칙 및 spec 충족 여부를 확인하고, 수정 사항이 있으면 `[PHASE: REVIEW_FEEDBACK]`을 전달하고 정합성이 확인되면 `APPROVAL (LGTM)`을 회신합니다.
5. 상호 피드백은 최대 3턴 이내에 수렴해야 하며, 3턴 초과 시 작업을 중단하고 `docs/swarm/results/T01.md`의 `## 막힌 것`에 원인을 기록한 뒤 상태를 실패로 마감합니다.

## 완료 조건

- [ ] `from models import Netlist, Module, Port, Wire, Instance, PinConnection, Alias`가 정상 임포트된다.
- [ ] `Wire` 클래스가 `is_implicit: bool = False` 필드를 포함한다.
- [ ] `pytest tests/test_models.py` 실행 시 모든 모델 테스트가 통과한다.
- [ ] 모든 데이터 클래스가 `slots=True` 속성을 가지며 외부 라이브러리 의존성 없이 표준 라이브러리만 사용한다.

## 검증

`pytest tests/test_models.py`
