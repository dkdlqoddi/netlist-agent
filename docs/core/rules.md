## 관례

| 분류 | 관례 | 근거 |
|---|---|---|
| 폴더 구조 | 모든 소스 코드는 src/ 아래에 계층별로 분리하여 배치한다. | conventions F3 |
| 이름 짓기 | 파일과 함수는 snake_case, 클래스와 도메인 엔티티는 PascalCase를 쓴다. | conventions F2 |
| 오류 처리 | 문법 오류나 제약 위반 발생 시 명확한 메시지와 함께 즉시 실패(Fail-fast)한다. | conventions F4 |
| 아키텍처 | 도메인 모델은 순수 데이터 정의만 담고 다른 모듈을 참조하지 않는다. | conventions F2 |
| 테스트 | 단위 및 통합 테스트는 tests/ 디렉토리에 배치하고 pytest로 실행한다. | conventions F1 |

| 인스턴스 (Instance) | 정의된 부품 모듈을 회로 상에 실제로 배치한 개별 부품 | IEEE 1364 |
| 핀 (Pin) | 부품 인스턴스에서 외부 신호선과 연결되는 물리적/논리적 접점 | IEEE 1800 |

| 하이퍼그래프 (Hypergraph) | 하나의 신호선이 여러 부품 핀에 동시에 연결되는 다대다 회로 구조 | https://arxiv.org/abs/2404.00477 |
