머지 전 퀴즈: 반도체 넷리스트 파싱 및 데이터베이스 구조화

대상: docs/core/specs/netlist-parser.md · 기준: d2c10b9

변경 요약

반도체 회로의 연결 정보를 담은 텍스트(넷리스트)를 읽어 데이터베이스에 체계적으로 저장하는 기능을 구현했습니다. 회로를 이루는 부품, 입출력 통로, 신호선, 부품 단자 연결, 별칭 정보를 각각 분리하여 여섯 개 표로 저장합니다. 실제 회로처럼 상위 모듈과 하위 모듈이 연결된 예시 넷리스트 파일과 실행 코드를 함께 제공합니다. 설명 글(주석)이 섞여 있거나 이름이 미리 선언되지 않은 신호선이 단자에 연결되어도 자동으로 기본 신호선으로 등록합니다. 외부 데이터베이스 서버를 설치할 필요 없이 기본 내장 데이터베이스(SQLite)를 사용하여 독립적으로 동작합니다. 단자 연결 시 이름을 생략하고 순서대로만 연결하는 방식은 모호함을 방지하기 위해 지원하지 않습니다. 저장 중에 문제가 생기면 작업을 취소하고 원래 상태로 되돌려 데이터가 훼손되지 않도록 보호합니다.
